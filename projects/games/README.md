# משחקים אינטראקטיביים

כל פרויקט בקטגוריה הזו נמצא בתיקייה נפרדת משלו: `projects/games/<שם-הפרויקט>/`.

- פרויקט עם `package.json` נבנה אוטומטית (`npm run build`), והתוצר מתפרסם מתוך תיקיית `dist`.
- פרויקט בלי `package.json` מתפרסם כמו שהוא (HTML/CSS/JS רגילים).
- כל פרויקט מקבל כתובת משלו באתר: `.../projects/games/<שם-הפרויקט>/`
