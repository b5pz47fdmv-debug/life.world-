# HOTEL TYCOON 🏨

סימולציית ניהול אחוזת נופש יוקרתית. בנויה קודם כל לאייפון, ופועלת ישירות בדפדפן בעברית מלאה (RTL).

**סטטוס:** שלב 1 מתוך 6 (יסודות) ✅

## מה עובד בשלב 1
- **עולם איזומטרי מפורט** (PixiJS/WebGL) של אחוזת חוף: לובי מפואר, 4 חדרי אירוח מרוהטים עם חדר רחצה צמוד, מסדרון, גינות, מזרקה מונפשת, דקלים שמתנועעים ברוח, חוף עם ים מונפש, כביש ומכוניות.
- **שתי תצוגות:** "פנים" (חתך שרואים בו את החדרים) ו"חוץ" (חזית, מרפסות וגג עם מרפסת גג).
- **מחזור יום ולילה:** שעת זהב בערב, ובלילה הפנסים, החלונות והתאורה הפנימית נדלקים.
- **שעון משחק:** יום משחק נמשך כ־4 דקות. יש השהיה ומהירויות ×1, ×2 ו־×4.
- **שליטה במגע:** גרירה עם אינרציה, צביטה לזום, ולחיצה על חדר שמציגה כרטיס מידע.
- **ממשק ניהול:** סרגל עליון, 5 לשוניות, ומחירי חדרים שנשמרים.
- **שמירות:** שמירה אוטומטית כל 30 שניות וביציאה מהאפליקציה, גיבוי אוטומטי בתחילת כל יום משחק (עד 5), עד 10 גיבויים ידניים, שחזור, מחיקה, ייצוא לקובץ וייבוא ממנו, והתאוששות משמירה פגומה.
- **אפשר להוסיף למסך הבית** (PWA): אייקון ומסך מלא.

## ארכיטקטורה
```
src/
  core/        Game (תזמור), GameClock, SaveManager + migrations, EventBus
  sim/hotel/   layout.ts: מערכת הבנייה (ולידציה, קומות, אזורים, קירות אוטומטיים)
  data/        catalog.ts (סוגי חדרים, מתקנים וצוות) ו־initialState.ts (המלון ההתחלתי)
  state/       types.ts: מצב המשחק. כל מה שנשמר נמצא כאן בלבד.
  render/      WorldRenderer, Camera, iso, isoSort, architecture, furniture, outdoor, characters
  ui/          UI, panels, components, styles.css (DOM מעל ה־canvas)
  i18n/        he.ts. בעתיד יתווסף en.ts.
```
**עקרונות:**
1. **הסימולציה נפרדת מהתצוגה.** קוד ה־`sim` וה־`core` לא מכיר את PixiJS ואת ה־DOM, ולכן אפשר לבדוק אותו בבדיקות יחידה.
2. **מבנה מבוסס נתונים.** כדי להוסיף סוג חדר או מתקן מוסיפים רשומה ב־`catalog.ts`.
3. **מערכת בנייה גמישה.** בניין הוא מלבן עם N קומות. כל אזור (חדר, לובי, ספא) הוא מלבן בקומה, ויכולים להיות לו תתי־אזורים (כמו חדר רחצה בתוך חדר). הקירות והדלתות מחושבים אוטומטית מתוך גבולות האזורים. `addFloor`, `addArea` ו־`addGuestRoom` כבר עובדים וכבר נבדקים.
4. **שמירות עם גרסה.** כל שינוי במבנה השמירה מקבל מיגרציה ב־`migrations.ts`, כך ששמירות ישנות ממשיכות לעבוד.

## פיתוח
```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות יחידה (Vitest)
npm run build      # בדיקת טיפוסים ובנייה ל־dist/
npm run e2e        # בדיקת קצה־לקצה על אייפון מדומה (דורש Playwright ושרת preview)
```
